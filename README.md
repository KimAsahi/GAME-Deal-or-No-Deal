# Deal-or-No-Deal 白日梦想家 · 游戏规则

> 本文只记录规则本身，规则由玩家制定，未经同意不作改动。
> 定位：情侣小游戏，重在过程乐趣，不必纠结期望值与平衡。

## 一、角色

- 双人游戏，一方为「银行家」，一方为「梦想家」。

## 二、牌堆

- 牌堆由若干张卡片组成，张数由玩家自行决定。
- 每张卡片只有一个值，由玩家自行制定：可以是数字，也可以是其他内容。
- 卡片内容对双方公开，游戏中全程显示；每翻开一张，该选项即被划掉。

## 三、开局

1. 梦想家向银行家支付入场费，金额由玩家决定。
2. 梦想家从牌堆中抽取若干张卡片作为底牌，张数由玩家决定。
3. 底牌内容梦想家不得查看，银行家同样不知道。
4. 底牌若为多张，银行家须将其一并买走。

## 四、回合

- 第 1 轮：银行家出价，梦想家决定是否以此价格卖出底牌；不接受则进入下一轮。
- 后续每轮：梦想家必须亲自从牌堆翻开一张牌（双方可见），随后银行家再次出价，梦想家决定是否卖出。
- 出价不设限制。

## 五、结束

- 梦想家接受出价：游戏立即结束，可翻开底牌。
- 牌堆最后一张牌被翻开：游戏立即结束，梦想家保留底牌。

## 六、金额

- 入场费归银行家。
- 梦想家卖出底牌：银行家按出价支付，底牌归银行家。
- 梦想家保留底牌到最后：银行家按底牌上的金额支付给梦想家。
- 示例：入场费 20，底牌抽到 10，银行家出价 50 买走，则梦想家赢下 20。

## 七、软件行为约定

- 全程显示全部卡片；翻开一张即划掉一张。
- 游戏结束时提示结束，并展示最终结果（底牌、成交价、入场费等）；不做结算。
- 单局制。
- 预设牌堆：可提前保存多套牌堆。
- 随机金额：给定金额范围与卡牌数，由系统随机生成每张卡片的金额。

## 八、附注（不属于规则，仅供确认）

- 梦想家保留底牌到最后时，银行家付款后奖品（卡片）归谁——原规则只写了「付底牌上的钱」，未写归属。
